{# Tăng giảm: ▲ xanh / ▼ đỏ (quy ước bảng giá Việt Nam), kèm chữ ẩn cho trình đọc màn hình. ``unit``: "trieu" (đồng -> triệu), "usd" (1 số lẻ khi cần), còn lại số nguyên. ``zero``: chữ khi bằng 0 - vàng để "–" (không ghi "đứng giá" vì nguồn trả 0 cả khi thiếu số), xăng ghi "0" (giữ nguyên). Không có số: "–". #} {% macro delta(value, unit="vnd", zero="–") -%} {%- if value is none -%} – {%- elif value == 0 -%} {{ zero }} {%- else -%} {%- set size = value | abs -%} {%- set text = (size | trieu) if unit == "trieu" else ((size | usd) if unit == "usd" else (size | vnd)) -%} {{ "▲" if value > 0 else "▼" }}{{ "tăng " if value > 0 else "giảm " }}{{ text }} {%- endif -%} {%- endmacro %}
