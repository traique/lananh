{# Tăng giảm: ▲ xanh / ▼ đỏ (quy ước bảng giá Việt Nam), kèm chữ ẩn cho trình đọc màn hình. ``unit``: "trieu" (đồng -> triệu), "usd" (1 số lẻ khi cần), còn lại số nguyên. ``zero``: chữ khi bằng 0; trống (vàng) thì coi như không có số, vì nguồn trả 0 cả khi thiếu số; xăng ghi "Giữ nguyên". Không có số: ô để trống, chỉ trình đọc màn hình đọc thành lời. #} {% macro delta(value, unit="vnd", zero="") -%} {%- if value is none or (value == 0 and not zero) -%} chưa có số tăng giảm {%- elif value == 0 -%} {{ zero }} {%- else -%} {%- set size = value | abs -%} {%- set text = (size | trieu) if unit == "trieu" else ((size | usd) if unit == "usd" else (size | vnd)) -%} {{ "▲" if value > 0 else "▼" }}{{ "tăng " if value > 0 else "giảm " }}{{ text }} {%- endif -%} {%- endmacro %}
